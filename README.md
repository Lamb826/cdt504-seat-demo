# Study Seat · CDT504 图书馆座位系统

首页先引导学生查看座位图，到桌后再扫码签到。分层地图使用小组提供的 Lingnan-Library-Seating-Plans.pdf，包含 1/F、M/F、2/F 和 3/F。楼层平面布局源于学校资料。彩色座位点按图中的桌椅位置选取，分区名称、座位编号和占用状态均为演示设定。计数只统计图上标点。

## 在本机试用

解压后，在包含 index.html 的文件夹打开终端，运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 [座位图](http://127.0.0.1:8765/seat-map.html)。同一浏览器下，签到页与地图共享本机演示状态。

## 汇报演示

1. 切换楼层，点区域名称可放大。每层已经安排空位、在座和暂离场景。
2. 在 1/F 选择「中央长桌」，点绿色 1F-A01。详情页可进入签到，表单自动填入对应编号。演示填写虚构姓名和学号，邮箱可留空。
3. 签到后，回到该层地图，座位显示在座。再演示暂离、返回或签出，地图会显示相应状态。模拟场景中的其他座位保持预设状态。
4. 桌贴签到支持 `index.html?seat=座位号` 链接。`seat-plate.html` 是独立的座位牌生成与打印页。生成时会调用外部二维码服务。

## 文件

- **index.html、base.css、app.js** 提供首页、签到表单和个人会话。
- **seat-map.html、map.css、map.js** 提供分层地图、分区放大、计数及详情。
- **floor-data.js、floors/** 存放演示座位与对应楼层底图。
- **checkin.html** 保留扫码签到入口。**manifest.json、sw.js、register.js** 用于安装与离线缓存。
- **config.js** 保留原版签到接口设置。默认本机演示。地图及演示座位只使用本机状态。

这是静态站点，解压后可直接通过本地 HTTP 或静态托管运行。座位图是课堂演示，公开图面只展示座位状态。
